# Task 3 — Password Generator

**CodSoft Python Programming Internship**

## 📌 Overview
A tool that generates strong, random passwords. The user specifies the
desired length and which character types to include (uppercase, lowercase,
digits, symbols), and the app generates and displays a secure password
using Python's cryptographically-strong `secrets` module.

## ✨ Features
- Custom password length
- Toggle uppercase / lowercase / digits / symbols
- Uses `secrets.choice()` for cryptographically secure randomness
- Generate multiple passwords in one session
