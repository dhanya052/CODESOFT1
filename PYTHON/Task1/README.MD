# Task 1 — To-Do List Application

**CodSoft Python Programming Internship**

## 📌 Overview
A command-line To-Do List application that helps users manage and organize
their tasks efficiently. Users can create, view, update, complete, and
delete tasks, and everything is saved to `tasks.json` so the list persists
between sessions.

## ✨ Features
- Add new tasks with an optional due date
- View all tasks with completion status
- Mark tasks as complete
- Update a task's title or due date
- Delete tasks
- Data persists automatically in `tasks.json`

## 🗂️ Files
| File | Description |
|---|---|
| `todo.py` | Main application source code |
| `tasks.json` | Sample/starter data file (auto-created & updated as you use the app) |
| `requirements.txt` | Dependencies (none — standard library only) |
| `outputs/sample_run.txt` | Example of a sample terminal session |

## ▶️ How to Run
```bash
python todo.py
```
Then follow the on-screen menu (1–6) to manage your tasks.

## 🧰 Requirements
- Python 3.7+
- No external packages needed
