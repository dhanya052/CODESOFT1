# Task 4 — Rock-Paper-Scissors Game

**CodSoft Python Programming Internship**

## 📌 Overview
A classic Rock-Paper-Scissors game played against the computer from the
command line. The computer's choice is randomized, the winner of each
round is determined automatically, and scores are tracked across
multiple rounds until the player chooses to stop.

## ✨ Features
- User input validation (accepts full words or `r` / `p` / `s` shortcuts)
- Randomized computer choice
- Automatic winner determination each round
- Running score tracker for user vs. computer
- "Play again?" loop with a final match summary
- Friendly, clear terminal interface
