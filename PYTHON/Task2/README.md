# Task 2 — Simple Calculator

**CodSoft Python Programming Internship**

## 📌 Overview
A simple command-line calculator that performs the four basic arithmetic
operations: addition, subtraction, multiplication, and division. The user
selects an operation and enters two numbers; the result is displayed
immediately, and the user can perform more calculations in the same session.

## ✨ Features
- Addition, Subtraction, Multiplication, Division
- Input validation (rejects non-numeric input)
- Handles division-by-zero gracefully
- Loop-based menu for multiple calculations per run
